# ☕ Transição JS ➔ Java & Programação Orientada a Objetos (POO)

Este repositório documenta a minha jornada de aprendizado na transição do desenvolvimento em **JavaScript** para **Java**, com foco na consolidação dos conceitos de **Programação Orientada a Objetos (POO)**.

O objetivo é registrar a evolução da sintaxe, tipagem e paradigma, comparando as abordagens do JS com a estrutura fortemente tipada e orientada a objetos do Java.

---

## 🔄 Transição: JavaScript vs. Java

Principais diferenças e adaptações exploradas nos primeiros códigos:

| Conceito | JavaScript | Java |
| :--- | :--- | :--- |
| **Tipagem** | Dinâmica (`let`, `const`) | Estática e Forte (`int`, `String`, `boolean`) |
| **Execução** | Interpretado (JIT) no Browser/Node | Compilado para Bytecode (`.class`) e rodado na JVM |
| **Escopo de POO** | Baseado em Protótipos | Orientado a Classes rígidas |
| **Entrada/Saída** | `console.log()` / `readline` | `System.out.println()` / `Scanner` |

---

## 📌 Conceitos de POO Abordados

- [x] **Sintaxe Básica e Tipagem:** Variáveis, operadores e estruturas de controle (`if`, `for`, `while`).
- [ ] **Classes e Objetos:** Atributos, métodos e construtores.
- [ ] **Encapsulamento:** Modificadores de acesso (`public`, `private`, `protected`) e métodos Getters/Setters.
- [ ] **Herança (`extends`) e Polimorfismo (`@Override`):** Reutilização de código e sobrescrita de métodos.
- [ ] **Abstração & Interfaces:** Uso de `abstract` e `interface` para definir contratos.
- [ ] **Tratamento de Exceções:** Uso de `try-catch` e `throws`.
